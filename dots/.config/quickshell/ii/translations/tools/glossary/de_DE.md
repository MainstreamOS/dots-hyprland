# German UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use German for Germany, the existing informal `du` register, and short noun or
infinitive action labels. Preserve existing sound translations. This glossary
records translation decisions, not native-speaker approval. Keep names, command
arguments, format tokens, units and user content unchanged. Use count-neutral
labels when a numeric placeholder can be 1. Keep Super; Strg, Umschalt and Entf
may name the corresponding physical keys in explanatory prose.
