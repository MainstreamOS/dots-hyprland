# Arabic UI terminology (ar_SA)

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Modern Standard Arabic for Saudi Arabia and the Arab region (العربية الفصحى الحديثة / المملكة العربية السعودية).
Uses established, natural computing vocabulary for desktop and mobile environments.
Technical identifiers, Latin command arguments, format placeholders (%1, %s), and
protected names (Wi-Fi, Bluetooth, CPU, GPU, etc.) remain in Latin script as required
by catalog QA rules.
