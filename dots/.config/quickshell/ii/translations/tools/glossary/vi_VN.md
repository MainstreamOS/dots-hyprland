# Vietnamese UI terminology (vi_VN)

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Neutral Vietnamese; omit personal pronouns where practical. Keep concise noun labels
and natural action verbs. Preserve good existing translations. This is a translation with independent context review, not native-speaker verification.

Keep command arguments, metavariables, paths, functional shortcuts, product names,
markup, units, joining whitespace and newline counts intact. Vietnamese nouns are
count-neutral. Translate effort labels; preserve literal accepted argument values.
`at` is a battery threshold, `Up %1` is uptime and `Launch on startup` is the lock
screen option. Record shared-key ambiguities in completion notes.
