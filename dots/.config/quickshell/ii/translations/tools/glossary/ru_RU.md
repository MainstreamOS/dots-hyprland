# Russian UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use Russian for Russia with polite `вы` in sentences and infinitive or noun labels.
Preserve sound existing translations. This glossary records translation decisions,
not native-speaker review. Preserve product names, commands, placeholders, units
and user content. Russian has several count forms but the lookup has no plural
support: use count-neutral labels such as `Файлов: %1` or invariant abbreviations.
Use `ё` where appropriate. Keep Super and literal key combinations intact.
