# Simplified Chinese UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Write concise standard Simplified Chinese for mainland China. Keep sound existing
translations and the existing neutral register. Use Chinese punctuation in prose,
but preserve command syntax, identifiers, URLs, paths, units and joining whitespace.
Chinese count phrases naturally support every count without plural inflection.
This glossary records translation decisions, not native-speaker review. Traditional
Chinese will be translated separately from English using Taiwan vocabulary.

Access token means 访问令牌, distinct from an LLM token (词元). The standalone
Border date-style label keeps the existing 内圈 for the clock, while window
borders use 边框. The shared Play key uses 播放 for media controls; the gaming
category needs a separate source key for 玩游戏.
