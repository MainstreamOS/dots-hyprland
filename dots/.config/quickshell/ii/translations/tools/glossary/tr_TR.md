# Turkish UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use standard Turkish, with polite plural imperatives in instructions and compact
verb or noun labels. Seed terms from sound existing translations. Turkish counted
nouns stay singular, so `%1 dosya` works for any count. Keep typed command names,
arguments, identifiers, paths, URLs and units literal. Preserve actual newlines
and joining whitespace. This records decisions, not native-speaker verification.
