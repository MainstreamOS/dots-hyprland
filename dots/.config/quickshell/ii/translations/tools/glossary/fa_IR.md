# Persian UI terminology (fa_IR)

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Standard Persian for Iran and Persian speakers (فارسی / ایران). Uses established,
natural computing vocabulary for desktop and mobile environments. Technical terms,
Latin command arguments, format placeholders (%1, %s), and protected names
(Wi-Fi, Bluetooth, CPU, GPU, etc.) remain in Latin script as required by catalog QA rules.
