# Italian UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use informal second-person instructions and concise infinitives or nouns for
labels. Retain sound existing terms. The existing locale calls tasks Promemoria,
the desktop Scrivania, downloads Scaricati, the tray Area di notifica and the
overview Panoramica. Preserve executable syntax, names, paths and real newlines.
Use count-neutral labels such as `Notifiche: %1` where one value serves every
count. This glossary records translation choices, not native review.
