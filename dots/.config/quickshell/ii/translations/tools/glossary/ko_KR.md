# Korean UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use standard Korean with 합니다/하세요 in sentences and concise noun or action
labels. Observe Korean word spacing. The initial catalog has no translated
values. Keep executable names, identifiers, paths, URLs, code, units and typed
command arguments intact. Preserve actual newlines and joining whitespace.
Korean count constructions do not require plural inflection. This records
translation choices, not native-speaker verification.

Subscription-access `Plan` uses 구독; the non-executing AI mode uses 계획.
`Dotfiles` uses 설정 파일; literal commands and repository names are unchanged.
`Quote` uses 인용문, `Crosshair` 조준선, and `Line-separated` 구분선으로 나누기.
Keep literal CLI choices such as list, pull and status in help argument lists.
