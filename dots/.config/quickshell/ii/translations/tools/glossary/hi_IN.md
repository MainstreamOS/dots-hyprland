# Hindi UI terminology (hi_IN)

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Standard Hindi for India (हिन्दी / भारत) in Devanagari script. Uses modern, natural
computing terminology familiar to Indian desktop and mobile users. Technical terms,
acronyms, and protected technology brands (CPU, GPU, RAM, Wi-Fi, Bluetooth, etc.)
are preserved in Latin script according to catalog QA rules.
