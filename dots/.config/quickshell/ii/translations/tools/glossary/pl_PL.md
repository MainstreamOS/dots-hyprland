# Polish UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use standard Polish software vocabulary, full diacritics, concise noun labels and
infinitives for actions. Prefer impersonal instructions. No existing translations
are available to seed this locale. Counts require special care: the lookup has no
plural support, so use labels such as `Pliki: %1`, not a noun inflected for one
specific number. Preserve command syntax, identifiers, paths, names, units and
actual newlines. This records translation choices, not native-speaker review.

## Updated reasoning decisions

Applies the owner’s 2026-10-28 guidance from `updated-reasoning/TERMINOLOGY.md`
and `HANDOFF.md`. Keep these names recognizable in all labels and prose:
Dotfiles/dotfiles, Cookie, Material cookie, Tonal Spot, Neutral, Fruit Salad,
Rainbow, Fidelity, Expressive, Monochrome, scratchpad, submap, fake fullscreen,
pseudo-tiling and Notch. Translate the surrounding words. Expressive font is a
font role, not the Expressive palette, and is translated normally.

Pill remains kapsułka, a capsule-shaped container, never pigułka/tabletka.
Hug is Rozciągnięty, an edge-spanning style, not an embrace or merely edge-attached.
Float / Notch / Hug / Rect use Pływający / Notch / Rozciągnięty / Prostokątny.
Blur and frost share rozmycie throughout. Tray stays Zasobnik; System tray is
Zasobnik systemowy. Short Island labels use wyspa; Dynamic Island stays the named
feature. Home stays Katalog domowy. Unmuted is Dźwięk włączony. Earbang protection
is Limit skoków głośności, referring to sudden volume increases.

Source exception: standalone Swap is Pamięć wymiany, because its current callers
are memory statistics (`Resources.qml`, `ResourcesPanel.qml`, `ResourcesPopup.qml`).
Window exchanges use Zamień in their own keys. The supplied offline es_MX review
inferred the wrong sense of that shared standalone key; do not apply it blindly.
Budget is the model’s processing allowance, never a monetary limit. UI reasoning
levels are translated; literal accepted command arguments and metavariables stay
English. The invariant export-count suffix images is obr. (abbreviation for image),
so 1 obr., 2 obr. and 5 obr. all compose without a plural API.

Long established Polish desktop terms that cannot be shortened without changing
scope are candidates for later UI fit checks, not reasons to invent new feature
names. Launcher is the compact desktop loanword, with launcher aplikacji for app
launcher and Przegląd launchera for Launcher Overview; the scrolling-layout label
keeps both layouts. The updater’s launcher exit code names a helper process, so
it uses program uruchamiający rather than the desktop feature name.

Kernel scheduler is planista, distinct from a systemd timer’s harmonogram.
The pin-state adjective for the sidebar is masculine przypięty. AI voice input
sends podyktowany tekst, whereas the phone records a wiadomość głosowa. Streamer
mode ukrywa Island alerts; it does not disable calls or messages on the phone.
