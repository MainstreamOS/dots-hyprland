Use count-neutral labels when numbers need Ukrainian plural forms: e.g. «Сповіщення: %1», «Символів: %1». Preserve names, literal metavariables, commands, units, formats, markup and joining whitespace. Memory Swap is Своп; window exchanges use поміняти місцями. Budget retains established computing-budget usage, not a monetary price. Full Dynamic Island stays named; short Island compounds use острів. No direction marks are added.

Source-specific decisions after review: battery-threshold at is «за рівня»; Up %1 is uptime. No output in the audio panel is «Немає аудіовиходу». Refresh local models means refreshing their list. Recipient/author labels use case-neutral constructions around untouched runtime names; Replying to %1 is «Відповідь (%1)» with yourself «собі». Literal ms/min/h tokens are preserved.
