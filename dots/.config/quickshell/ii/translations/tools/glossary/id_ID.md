# Indonesian UI terminology

Current display-name policy and all 19 locale decisions are in
[TERMINOLOGY.md](../../TERMINOLOGY.md). That consolidated guide supersedes earlier
English-preservation instructions in historical notes.


Use standard Indonesian software vocabulary and the existing catalog’s polite
Anda register. Labels use short nouns or imperative verbs; preserve established
existing translations unless they have a concrete error. Indonesian count nouns
are invariant, so do not add reduplication just because a runtime count is plural.
Keep full command syntax, metavariables, names, units, newlines and joining spaces.
Apply the owner’s updated 2026-10-28 terminology guidance alongside the original
translation handoff. These are translation choices, not native-speaker verification.

The named presets, Cookie, Material cookie, Dotfiles, Dynamic Island, Notch,
Superpaste, scratchpad, submap, fake fullscreen and pseudo-tiling stay recognizable
in English. Ordinary surrounding prose translates. Short Island compound labels
use Pulau, the short Indonesian word for island, rather than adding Dynamic.
The shape Rect requires the two-word Persegi panjang: Persegi alone means square
and would be wrong. Accurate established compounds take precedence over a strict
one-word preference. Swap in the current resource panels is memory, not an action.

Use Pewaktu for the countdown UI; systemd .timer units use Timer in their technical
update-log context. Personal secrets are Ring kunci; trusted signing keys are
Kumpulan kunci (paket). Memory swap remains Swap, while window actions use Tukar.
Files is File, an invariant Indonesian loanword, not the English plural Files.
Home is Folder pribadi, not Rumah or a start page. The desktop helper’s launcher
exit-code message refers to a helper process, not an app-drawer error. Voice input
is Input suara (AI transcription input), distinct from a phone Pesan suara.

Up %1 in the uptime widget is Aktif %1, not a direction. A click-only effort
cycle tooltip translates its visible levels, while command examples retain
minimal/low/medium/high/auto exactly.
